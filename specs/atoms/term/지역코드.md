## Definition

- 단위: **시군구** (서울 강남구, 수원시 수준) — 2026-08-19 제품 결정. 읍면동은 밀도 확보 후 세분화 후보
- 코드 체계: **행정표준코드(법정동 코드) 상위 5자리 — 2026-08-22 실측 검증 완료**
- GPS 좌표 → 시군구 매핑은 서버가 수행(`action-region-resolve`). 클라이언트는 좌표만 보낸다
- 표시명은 카카오 `coord2regioncode`(법정동 `B`) 응답과 1:1로 맞춘다. 판별 결과가 그대로
  lazy upsert되므로 마스터와 형태가 다르면 같은 지역이 두 표기로 갈린다
  - `name` = `region_2depth_name`. **일반구를 둔 시는 "수원시 장안구"처럼 시+구가 통째로 들어간다**
  - `fullName` = `region_1depth_name` + 공백 + `region_2depth_name`
  - 세종특별자치시는 `region_2depth_name`이 비어 있어 `region_1depth_name`이 곧 표시명이다
- **마스터 시드**: 전국 256개 시군구를 마이그레이션으로 넣는다
  (`apps/api/drizzle/0002_region-seed.sql` — 출처와 생성 방법을 파일 주석에 기록)

### 행정구역 개편 대응 (2026-08-22 확정 — 기존 오픈 퀘스천 해소)

시군구 코드는 **불변이 아니다.** 2026-07-01 개편으로 실제로 다음이 바뀌었고, 시드 작업 중
카카오 실측으로 발견했다.

| 개편 | 코드 영향 |
|---|---|
| 전남광주통합특별시 출범 (광주광역시 + 전라남도) | 시도 코드 `29`·`46` 폐지 → `12`로 이관, 27개 시군구 |
| 인천 자치구 재편 (제물포구·영종구·서해구·검단구 신설) | 중구·동구·서구 폐지, 10개 → 11개 |
| 화성시·부천시 일반구 설치 | 화성시 → 4개 구, 부천시 → 3개 구 |

대응 원칙:

- **마스터 갱신은 새 마이그레이션으로만 한다.** 이미 적용된 시드 파일을 고치면 drizzle 해시
  검증에 걸리고, 운영 DB와 로컬이 갈린다
- **구 코드 행을 삭제하지 않는다.** `votes.region_code`·`accounts.region_code`가 참조하므로
  삭제는 외래키 위반이거나 이력 손실이다. 폐지된 지역은 `active=false`로 내린다
- 공개 법정동코드 데이터셋은 개편 반영이 늦다. **진실은 카카오 응답**이며,
  마스터를 다시 만들 때는 카카오 실측으로 교차 검증한다
- **오픈 퀘스천**: 폐지 지역에 남은 계정·투표의 이관 정책 (현재는 미결 — 개편 시 사용자가
  재판별하면 새 코드로 옮겨가지만, 오래된 집계는 구 코드에 남는다)

## Usage Context

- **오픈 퀘스천**: 해외/좌표 판별 불가 지역 fallback
