# 집계조회

**구현 앵커:**

| 레이어 | 경로 |
|------|------|
| route | `apps/api/src/routes/feed.ts` — `GET /v1/feed` |
| service | `apps/api/src/services/feed.ts`, `apps/api/src/services/tally.ts` |
| test | `apps/api/test/api.test.ts` — 피드·최소표본·슬라이딩윈도우 |

## Rationale

_(TBD)_

## Auth & Permissions

- 익명 기기 계정 토큰 (내 지역·내 투표 상태를 함께 반환하기 위해)

## Execution Order

1. 계정의 캐시된 지역 확인
2. 내 지역의 날씨 [집계결과][entity-tally] + 활성 큐레이션 주제 집계 조회 ([슬라이딩윈도우-집계][rule-sliding-window-tally] 적용분)
3. 표본 미달 지역은 [최소표본-표시][rule-min-sample-display] 상태로 마킹
4. 내 유효 표(선택지)와 크레딧 잔액을 포함해 응답

## Input / Output

- 입력: 없음 (계정 토큰으로 지역·상태 유도) 또는 명시적 지역코드
- 출력: 위젯 1회 렌더에 필요한 전부 — 지역명, 1위 선택지·비율, 총 표수, 집계 시각, 내 표, 크레딧 잔액, 활성 주제 목록

## DO NOT

_(TBD)_

- (초안) 위젯 전용 경량 응답과 앱 홈 응답을 별도 API로 쪼개지 않는다 — 스키마 분화가 위젯 갱신 버그의 온상
