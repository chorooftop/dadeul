## 방향 (확정 결정)

| 축 | 결정 | 의미 |
|---|---|---|
| 무드 | **맑고 산뜻한 날씨앱 감성** | 정보가 먼저 읽히는 유틸리티. 장식보다 여백·위계 |
| 컬러 | **화이트·라이트 베이스** | 흰 바탕에 스카이 블루 악센트 (2026-08-20 개정 — 네이비 다크는 어색하다는 피드백으로 폐기) |
| 타이포 | **Pretendard** | 앱에 번들(SIL OFL 무료). 숫자·한글 균형이 좋아 집계 수치 표기에 유리 |
| 위젯 위계 | **분포 중심 + 개표 현황 스타일** | 네이버 대한민국 선거 개표 UI 참고 — 순위 뱃지·득표 바·굵은 수치. "의견이 갈린다"는 실시간감 전달 |

## 타이포 스케일 (Pretendard)

| 역할 | 크기/웨이트 |
|---|---|
| 화면 타이틀 (지역명) | 24 ExtraBold |
| 카드 제목 | 17 Bold |
| 위젯 1위 수치 | 22~26 ExtraBold |
| 본문·선택지 | 14 Medium |
| 캡션 (참여·시각) | 11~12 Regular |

시안 도구에서 Pretendard를 못 쓰는 환경이면 Noto Sans KR로 대체하고 문서에 표기한다 (현 Claude Design 캔버스가 이 경우 — 상단 시안 원본 항목 참조). 앱 구현은 Pretendard 번들이 기준이다.

## 위젯 원칙

- **개표 현황 스타일** (네이버 선거 UI 참고): 순위 뱃지(①②③) + 라벨 + 득표 바 + 굵은 % 를 행으로 쌓는다. 1위 행은 `sky` 바·수치 + `sky-tint` 하이라이트, 2위 이하는 회색 계열
- **분포가 주인공**: small도 상위 2~3개 옵션을 보여준다. medium은 4개 + 득표수("n표") 병기
- 지역명 + 라이브 닷은 상단 고정, "n분 전"은 하단 고정 (낡음 정직 표기 — spec-weather-vote-widget Core Requirement 3)
- 표본 미달: 바 대신 참여 유도 문구 + `amber` 포인트 (rule-min-sample-display). 문구는 2단계 —
  0명 "현재 위치의 첫 투표를 기다려요" / 1~4명 "5명이 모이면 결과가 보여요" (+ "지금까지 n명" 병기).
  참여가 있는데 "첫 투표를 기다려요"를 쓰지 않는다 (자기모순, 2026-08-21 교정)
- 아이콘은 SF Symbol만 사용 — 이모지 금지 (렌더링 환경 의존 제거)
- 위젯 콘텐츠는 feed 스냅샷만으로 렌더 가능해야 한다 (지역명·counts·totalVotes·computedAt·sampleSufficient)

## 스플래시·온보딩 (2026-08-22 확정)

- **스플래시**: 미니멀 워드마크 — `bg` 배경, 라이브 닷 + "다들" 워드마크(40 ExtraBold, 스플래시 전용 스케일) +
  태그라인 "지금, 다들 어떠신가요?" (2026-08-22 개정 — 서비스명 호명 톤, 홈 카드 질문 톤과 통일; 구 "투표로 결정된 지금")(14 Medium `ink-sub`), 하단 원형 스피너 로딩 인디케이터 (점 3개 금지 — 온보딩 페이지 닷과 혼동, 2026-08-22 교정). 계정 자동 생성은 이 화면 뒤에서 진행
- **온보딩 3장 스와이프** (최초 1회, 1~2장 우상단 "건너뛰기"):
  1. 서비스 소개 — "현재 위치의 지금 날씨, 투표로 알아요" + 집계 카드 일러스트
  2. 위젯 가치 — "홈 화면에서 바로 확인" + small 위젯 일러스트 (30분 주기 갱신 언급)
  3. 위치 안내 — "위치는 시군구까지만 사용해요" + "정확한 위치는 저장하지 않아요" → [시작하기] CTA(`sky` 필), 아래 "시작하면 위치 권한을 요청해요" 캡션
- 페이지 닷: 활성 `sky` / 비활성 `stroke`. CTA 높이 52 이상(터치 타깃 44+), 라운드 14
- 시안: design/ 캔버스 `Splash` / `Onboarding1~3` 아트보드

## 금지·주의

- 내부 정책 용어를 사용자 문구에 그대로 쓰지 않는다 — 예: "신선한 신호/참여"(rule-credit-grant)는
  "크레딧은 새로 참여할 때만 적립돼요"로 풀어쓴다 ("신성한"으로 오독된 사례, 2026-08-21 교정)
- 선택지 노출 집합·표본 판정을 클라이언트에서 재계산해 디자인에 반영하지 않는다 (서버 `visibleOptions`·`sampleSufficient`가 진실)
- 다크 베이스에서 `ink-sub` 미만 대비로 수치를 표기하지 않는다 (집계 수치는 항상 `ink` 이상)
