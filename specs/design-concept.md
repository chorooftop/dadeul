# 다들 디자인 컨셉

> 2026-08-20 사용자 인터뷰로 확정. 앱·위젯 UI 작업은 이 문서를 기준으로 한다.
> 시안 원본: Figma (chorooftop@gmail.com 계정) — PLAN/2026-08-20-design-pass.md 참조.

## 방향 (확정 결정)

| 축 | 결정 | 의미 |
|---|---|---|
| 무드 | **맑고 산뜻한 날씨앱 감성** | 정보가 먼저 읽히는 유틸리티. 장식보다 여백·위계 |
| 컬러 | **화이트·라이트 베이스** | 흰 바탕에 스카이 블루 악센트 (2026-08-20 개정 — 네이비 다크는 어색하다는 피드백으로 폐기) |
| 타이포 | **Pretendard** | 앱에 번들(SIL OFL 무료). 숫자·한글 균형이 좋아 집계 수치 표기에 유리 |
| 위젯 위계 | **분포 중심 + 개표 현황 스타일** | 네이버 대한민국 선거 개표 UI 참고 — 순위 뱃지·득표 바·굵은 수치. "의견이 갈린다"는 실시간감 전달 |

## 컬러 토큰

라이트 단일 테마로 시작한다 (다크 모드는 후속 결정).

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#F5F6F8` | 화면 배경 |
| `surface` | `#FFFFFF` | 카드·위젯 표면 |
| `stroke` | `#E8EBF0` | 카드 보더, 바 트랙 |
| `ink` | `#17181C` | 본문·수치 텍스트 |
| `ink-sub` | `#6B7280` | 보조 텍스트 (라벨, 참여 수) |
| `ink-ter` | `#9AA1AC` | 삼차 텍스트 ("n분 전") |
| `sky` | `#3D7BFF` | 프라이머리 — 1위 바·수치, 선택 상태, 순위 뱃지 |
| `sky-tint` | `#EAF1FF` | 선택 칩 배경, 1위 행 하이라이트 |
| `amber` | `#FFB324` | 크레딧, 참여 유도(표본 미달) |

## 타이포 스케일 (Pretendard)

| 역할 | 크기/웨이트 |
|---|---|
| 화면 타이틀 (지역명) | 24 ExtraBold |
| 카드 제목 | 17 Bold |
| 위젯 1위 수치 | 22~26 ExtraBold |
| 본문·선택지 | 14 Medium |
| 캡션 (참여·시각) | 11~12 Regular |

Figma 시안에서 Pretendard를 못 쓰는 환경이면 Noto Sans KR로 대체하고 문서에 표기한다.

## 위젯 원칙

- **개표 현황 스타일** (네이버 선거 UI 참고): 순위 뱃지(①②③) + 라벨 + 득표 바 + 굵은 % 를 행으로 쌓는다. 1위 행은 `sky` 바·수치 + `sky-tint` 하이라이트, 2위 이하는 회색 계열
- **분포가 주인공**: small도 상위 2~3개 옵션을 보여준다. medium은 4개 + 득표수("n표") 병기
- 지역명 + 라이브 닷은 상단 고정, "n분 전"은 하단 고정 (낡음 정직 표기 — spec-weather-vote-widget Core Requirement 3)
- 표본 미달: 바 대신 "현재 위치의 첫 투표를 기다려요" + `amber` 포인트 (rule-min-sample-display)
- 아이콘은 SF Symbol만 사용 — 이모지 금지 (렌더링 환경 의존 제거)
- 위젯 콘텐츠는 feed 스냅샷만으로 렌더 가능해야 한다 (지역명·counts·totalVotes·computedAt·sampleSufficient)

## 금지·주의

- 선택지 노출 집합·표본 판정을 클라이언트에서 재계산해 디자인에 반영하지 않는다 (서버 `visibleOptions`·`sampleSufficient`가 진실)
- 다크 베이스에서 `ink-sub` 미만 대비로 수치를 표기하지 않는다 (집계 수치는 항상 `ink` 이상)
